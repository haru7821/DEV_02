# 인공신장실(혈액투석실) 도면 에디터

병원 인공신장실의 평면 배치를 그리고, 의료 규격을 자동 검증하며, A4 가로모드 PDF로 출력하는 싱글 페이지 애플리케이션(SPA)입니다.

## 실행 방법

빌드 과정이 없습니다. 저장소를 받은 뒤 정적 서버로 열면 됩니다. (라이브러리는 `vendor/`에 번들되어 있어 인터넷이 없는 병원 내부망에서도 동작합니다.)

```bash
# 예시: 파이썬 내장 서버
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 좌표계와 축척

캔버스 모델 좌표 **1px = 실제 1cm**로 고정하고, 화면 표시는 Fabric.js의 zoom으로만 조절합니다.
따라서 객체의 `left / top / width / height` 값이 곧 실제 치수(cm)이며, 검증 로직이 별도 환산 없이 동작합니다.
**UI의 모든 수치 입력·표시는 mm 단위**이며, `app.js`의 `toMM()/toCM()` 헬퍼가 화면 경계에서만 변환합니다.

## 병상 간격 검증 공식

두 병상의 (회전 반영) 바운딩 박스 A, B에 대해 **테두리 간 최단 거리**를 계산합니다.

```
dx = max(0, A.left − B.right, B.left − A.right)   // 가로축 이격
dy = max(0, A.top − B.bottom, B.top − A.bottom)   // 세로축 이격
gap = Math.hypot(dx, dy) = √(dx² + dy²)           // 피타고라스 정리
```

- 겹치면 `dx = dy = 0` → `gap = 0`
- 좌우로만 떨어져 있으면 `gap = dx` (대각선 아님)
- 대각선 방향이면 모서리 간 거리 `√(dx² + dy²)`

`gap < 80cm`(기준 **800mm** — 25BED 도면 실측)이면 위반으로 판정하며, 화면에는 mm로 표시됩니다. 기준값은 `js/assets.js`의 `MEDICAL_RULES`에서 수정할 수 있습니다.

### 검증 기준의 근거

- **업로드 실측 도면**(`reference-plans/`)이 1차 기준입니다. 나란한 병상 사이 **800mm**(침대 폭 900 + 간격 800 = 피치 1,700), 배관 콘솔 **640mm**, 통로 최소 **1,160mm**를 도면에서 직접 읽어 적용했습니다.
- 도면에 치수가 없는 **병상당 면적**만 보건복지부·대한신장학회 「인공신장실 설치 및 운영 세부기준 권고안」의 **6m² 이상**(지원실 제외한 환자 점유 공간)을 사용합니다.
- 등맞댐(back-to-back) 병상 쌍은 사이에 콘솔이 있으면 정상 배치로 보고 이격 검증에서 예외 처리합니다 — 27bed의 640mm 콘솔 구조 그대로입니다.
- 장비 카탈로그의 투석기 치수(Fresenius 4008S/6008, Baxter AK98, Nipro Surdial X, 투석 체어)는 제조사 기술자료 실측값(cm)으로, 장비 선택용 참고 자료입니다.

## Auto Modeling 배치 원리 (업로드 도면 분석 기반)

업로드된 실측 도면(`reference-plans/25BED.png` · `27bed.png`)과 초기 첨부 도면을 분석해 도출한 규칙이 알고리즘에 반영되어 있습니다. 치수 기본값은 모두 [기본 규격 — 업로드 실측 도면 기준](#기본-규격--업로드-실측-도면-기준)을 따릅니다.

1. **스테이션 시야**: N.S는 주 출입구 옆에 개방 카운터(문 없음, 개방면 표시)로 배치되어 출입구와 병상 필드를 동시에 관찰한다.
2. **소음 격리**: 정수실(RO)은 병상 밀집 구역에서 가장 먼 기술 밴드 최하단 코너에 배치한다.
3. **면적 배분 1:1**: 부속시설 면적이 전체의 약 50%가 되도록 실 크기를 배율(k)로 확대한다. 실별 크기를 직접 지정하면 지정값이 우선한다.
4. **콘솔 양면 배치**: 하나의 배관 콘솔을 사이에 두고 위(머리↓)/아래(머리↑) 양방향으로 병상을 설치한다(back-to-back). 콘솔로 분리된 병상 쌍은 이격 거리 검증에서 예외 처리된다.
5. **실 특성별 내/외부 배치**: 오염·설비 계열은 외벽 쪽 기술 밴드에 위(오염: 오물·세탁·기구세척)→중간(청결: 린넨·창고·코어)→아래(직원 지원 + 정수실) 순으로, 환자 접근 실은 하단 밴드에 안쪽(조제)→출입구 쪽(화장실→탈의→대기) 순으로 배치한다.
6. **오물처리실 = 반출입 코너**: 오물처리실을 외벽 열(col 0) **최상단**에 예약 배치해 상단 외벽 + 측면 외벽 두 면에 접하게 하고, 내부 복도 미닫이 + 측면 외벽 반출구 + **상단 외벽 반출입구(오물 반출·물품 입고)** 문을 단다. 환자 주 출입구(하단)와 대각으로 가장 멀어 청결/오염 동선이 교차하지 않는다.
7. **문 앞 통로**: 모든 출입문을 통과하면 바로 통로가 되도록 기술 밴드 앞 세로 복도, 환자 밴드 앞 가로 복도(각 1,300mm)와 출입구 세로 주 동선을 병상 금지 구역으로 확보한다.
8. **동선-배관 분리**: 주 동선을 병상 필드 가장자리에 배치해 배관 주행선이 통로를 가로지르지 않고, 트렁크 배관은 기술 밴드 벽체 매입 체이스로, 수평 주행은 콘솔(바닥 트렌치) 내부로만 지난다.
9. **계통 분리**: 정수실 내부 배관과 신장실 배관은 서로 연결하지 않는다 — 신장실 트렁크는 정수실 벽면의 「RO 인계점」에서 시작한다.
10. **실별 기본 오브젝트**: 각 실 용도에 맞는 집기(스테이션 2인 데스크 유닛, 탈의실 락커, 화장실 변기·세면대, 대기실 의자, 창고 선반, 세척 싱크, 격리실 손세정대)를 자동 배치하며, 문 개폐 구역과 겹치면 반대편으로 회피해 **오브젝트가 문 입구를 막지 않는다**.
11. **간호 스테이션 좌석**: 2인 책상+의자 유닛 단위로 2/4/6/8석을 선택해 스테이션 내부에 배치한다. 스테이션은 출입구 옆 + 병상 필드 개방면 위치.
12. **보조 동선**: 주 동선에서 각 병상 통로·환자 밴드 앞 복도로 이어지는 간호(치료) 이동로를 초록 점선 양방향 화살표로 표시한다.
13. **N.S 아일랜드 (2차 도면 분석)**: 간호 스테이션은 밴드 속 '방'이 아니라 병상 필드 안에 독립 배치된 **U자형 개방 카운터**다. 개방면이 병상 쪽을 향해 모든 병상 열을 관찰하고, 주 동선에 접해 출입구·처치실과의 이동이 짧다. 내부에 2인 데스크 유닛이 **1열로 병상을 바라보게**(의자가 뒤쪽 카운터 쪽, 상판이 병상 쪽) 들어간다.
14. **간호처치실은 N.S에 밀착**: 간호처치실은 상단 스트립에서 N.S와 벽을 공유한다(27bed 구성) — 처치·투약 준비가 스테이션 업무의 연장이기 때문이다. 스트립 폭이 모자라면 지정 폭보다 좁혀서라도 붙이고, 병상 모듈 2개 폭조차 남지 않으면 환자 밴드로 되돌린다. 반면 **간호사실(탈의·휴게)은 근무 공간이 아니므로 후방 밴드에 떨어져 배치**한다.
15. **처치실·조제실의 N.S 인접**: 간호처치실과 조제실은 환자 밴드의 동선 쪽 끝(=N.S와 같은 복도 선상)에 배치해 직원 동선을 최소화하고, 환자 프런트(화장실·탈의실·대기실)는 그 반대편에 둬 동선이 교차하지 않는다.
16. **후방 실 누락 방지**: 선택한 후방 실의 높이 합이 열 용량을 넘으면 자동 실만 비례 축소해 전부 수용한다(최소 1,500mm 보장). 크기를 직접 지정한 실은 축소하지 않는다.
17. **정수실 내부 자동 모델링**: 원수 인입 → 이송펌프 → Multimedia/Softner/Carbon 전처리 3연 → 5μ 필터 → RO(CWP106H/CWP66) 처리 순서와 Heating·Control Box·Main Panel·배수구를 자동 배치한다.
