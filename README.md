# 인공신장실(혈액투석실) 도면 에디터

병원 인공신장실의 평면 배치를 그리고, 의료 규격을 자동 검증하며, A4 가로모드 PDF로 출력하는 싱글 페이지 애플리케이션(SPA)입니다.

## 실행 방법

빌드 과정이 없습니다. 저장소를 받은 뒤 정적 서버로 열면 됩니다. (라이브러리는 `vendor/`에 번들되어 있어 인터넷이 없는 병원 내부망에서도 동작합니다.)

```bash
# 예시: 파이썬 내장 서버
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 좌표계와 축척

캔버스 모델 좌표 **1px = 실제 1cm**로 고정하고, 화면 표시는 Fabric.js의 zoom으로만 조절합니다.
따라서 객체의 `left / top / width / height` 값이 곧 실제 치수(cm)이며, 검증 로직이 별도 환산 없이 동작합니다.
**UI의 모든 수치 입력·표시는 mm 단위**이며, `app.js`의 `toMM()/toCM()` 헬퍼가 화면 경계에서만 변환합니다.

## 병상 간격 검증 공식

두 병상의 (회전 반영) 바운딩 박스 A, B에 대해 **테두리 간 최단 거리**를 계산합니다.

```
dx = max(0, A.left − B.right, B.left − A.right)   // 가로축 이격
dy = max(0, A.top − B.bottom, B.top − A.bottom)   // 세로축 이격
gap = Math.hypot(dx, dy) = √(dx² + dy²)           // 피타고라스 정리
```

- 겹치면 `dx = dy = 0` → `gap = 0`
- 좌우로만 떨어져 있으면 `gap = dx` (대각선 아님)
- 대각선 방향이면 모서리 간 거리 `√(dx² + dy²)`

`gap < 80cm`(기준 **800mm** — 25BED 도면 실측)이면 위반으로 판정하며, 화면에는 mm로 표시됩니다. 기준값은 `js/assets.js`의 `MEDICAL_RULES`에서 수정할 수 있습니다.

### 검증 기준의 근거

- **업로드 실측 도면**(`reference-plans/`)이 1차 기준입니다. 나란한 병상 사이 **800mm**(침대 폭 900 + 간격 800 = 피치 1,700), 배관 콘솔 **640mm**, 통로 최소 **1,160mm**를 도면에서 직접 읽어 적용했습니다.
- 도면에 치수가 없는 **병상당 면적**만 보건복지부·대한신장학회 「인공신장실 설치 및 운영 세부기준 권고안」의 **6m² 이상**(지원실 제외한 환자 점유 공간)을 사용합니다.
- 등맞댐(back-to-back) 병상 쌍은 사이에 콘솔이 있으면 정상 배치로 보고 이격 검증에서 예외 처리합니다 — 27bed의 640mm 콘솔 구조 그대로입니다.
- 장비 카탈로그의 투석기 치수(Fresenius 4008S/6008, Baxter AK98, Nipro Surdial X, 투석 체어)는 제조사 기술자료 실측값(cm)으로, 장비 선택용 참고 자료입니다.

## Auto Modeling 배치 원리 (업로드 도면 분석 기반)

업로드된 실측 도면(`reference-plans/25BED.png` · `27bed.png`)과 초기 첨부 도면을 분석해 도출한 규칙이 알고리즘에 반영되어 있습니다. 치수 기본값은 모두 [기본 규격 — 업로드 실측 도면 기준](#기본-규격--업로드-실측-도면-기준)을 따릅니다.

1. **스테이션 시야**: N.S는 주 출입구 옆에 개방 카운터(문 없음, 개방면 표시)로 배치되어 출입구와 병상 필드를 동시에 관찰한다.
2. **소음 격리**: 정수실(RO)은 병상 밀집 구역에서 가장 먼 기술 밴드 최하단 코너에 배치한다.
3. **장비 수량 우선**: 기본은 실을 부풀리지 않고 제공된/기본 크기 그대로 두어 병상 공간을 먼저 확보한다. 목표 대수를 채운 뒤에만 남는 공간을 실에 돌려주며(부속시설 면적 약 50% 목표), 이때 병상이 줄면 되돌린다. 패널에서 직접 입력한 실은 대수 연동 없이 **입력값 그대로** 배치된다.
4. **콘솔 양면 배치 (가로·세로 2방식)**: 하나의 배관 콘솔을 사이에 두고 양방향으로 병상을 설치한다(back-to-back). 콘솔로 분리된 병상 쌍은 이격 거리 검증에서 예외 처리된다.
    - **가로 콘솔**: 콘솔이 좌우로 지나가고 위(머리↓)/아래(머리↑)에 병상 행이 놓인다. 밴드는 위→아래로 반복.
    - **세로 콘솔 (27bed 팟 구조)**: 콘솔이 위아래로 지나가고 좌(머리→)/우(머리←)에 병상 열이 놓인다. 밴드는 좌→우로 반복하며, 양 끝 열은 발쪽-벽 이격 800mm을 확보한다. 배관은 콘솔 안을 세로로 주행하며 좌우 병상으로 분기한다.
5. **실 특성별 내/외부 배치**: 오염·설비 계열은 외벽 쪽 기술 밴드에 위(오염: 오물·세탁·기구세척)→중간(청결: 린넨·창고·코어)→아래(직원 지원 + 정수실) 순으로, 환자 접근 실은 하단 밴드에 안쪽(조제)→출입구 쪽(화장실→탈의→대기) 순으로 배치한다.
6. **오물처리실 = 반출입 코너**: 오물처리실을 외벽 열(col 0) **최상단**에 예약 배치해 상단 외벽 + 측면 외벽 두 면에 접하게 하고, 내부 복도 미닫이 + 측면 외벽 반출구 + **상단 외벽 반출입구(오물 반출·물품 입고)** 문을 단다. 환자 주 출입구(하단)와 대각으로 가장 멀어 청결/오염 동선이 교차하지 않는다.
7. **문 앞 통로**: 모든 출입문을 통과하면 바로 통로가 되도록 기술 밴드 앞 세로 복도, 환자 밴드 앞 가로 복도(각 1,300mm)와 출입구 세로 주 동선을 병상 금지 구역으로 확보한다.
8. **주 동선은 출입구 구간만**: 주 동선은 출입구 → 환자 밴드 → 병상 필드 입구(문 앞 가로 복도)까지만 병상 금지 구역으로 잡는다. 필드 안쪽 이동은 밴드 사이 보조통로가 담당하므로, 세로 띠를 필드 끝까지 비워 두어 공간을 낭비하지 않는다.
8-1. **동선-배관 분리**: 주 동선을 병상 필드 가장자리에 배치해 배관 주행선이 통로를 가로지르지 않고, 트렁크 배관은 기술 밴드 벽체 매입 체이스로, 수평 주행은 콘솔(바닥 트렌치) 내부로만 지난다.
9. **계통 분리**: 정수실 내부 배관과 신장실 배관은 서로 연결하지 않는다 — 신장실 트렁크는 정수실 벽면의 「RO 인계점」에서 시작한다.
10. **투석기는 환자 기준 오른쪽**: 병상 모듈 안에서 투석기는 항상 침대(환자) 기준 **오른쪽**, 머리맡(콘솔) 쪽에 놓인다. 머리 방향이 반대인 행(headDown)은 환자의 오른쪽이 화면상 왼쪽이 되므로 모듈 중심을 기준으로 침대·투석기를 좌우 반전해 배치한다.
11. **실별 기본 오브젝트**: 각 실 용도에 맞는 집기(스테이션 2인 데스크 유닛, 탈의실 락커, 화장실 변기·세면대, 대기실 의자, 창고 선반, 세척 싱크, 격리실 손세정대)를 자동 배치하며, 문 개폐 구역과 겹치면 반대편으로 회피해 **오브젝트가 문 입구를 막지 않는다**.
12. **간호 스테이션 좌석**: 2인 책상+의자 유닛 단위로 2/4/6/8석을 선택해 스테이션 내부에 배치한다. 스테이션은 출입구 옆 + 병상 필드 개방면 위치.
13. **보조 동선**: 주 동선에서 각 병상 통로·환자 밴드 앞 복도로 이어지는 간호(치료) 이동로를 초록 점선 양방향 화살표로 표시한다.
14. **N.S 위치 2형식**: 간호 스테이션은 밴드 속 '방'이 아니라 병상 필드 안에 독립 배치된 **U자형 개방 카운터**이며, 두 가지 위치 중 하나로 배치된다.
    - **상단 스트립형**: 격리실 코너 옆에서 필드 상단을 가로지르며 아래(병상)를 관찰한다.
    - **중앙 아일랜드형 (25BED 도면형)**: 병상 필드와 환자 밴드 사이를 가로지르는 카운터 열로, 개방면이 **위쪽(병상)**을 향한다. `[N.S][간호처치실][조제실]`이 주 동선까지 이어져 열 전체가 필드를 관통하므로 카운터 옆에 빈 바닥이 남지 않는다. 참고 도면의 중앙 카운터(5,878mm, 5조 1열) 구성 그대로다. 개방면이 병상 쪽을 향해 모든 병상 열을 관찰하고, 주 동선에 접해 출입구·처치실과의 이동이 짧다.
    - 2인 데스크 유닛이 **1열로 병상을 바라보게** 놓인다 — 의자가 뒤쪽(카운터 쪽), 상판이 병상 쪽이라 앉으면 환자를 정면으로 본다. 데스크 열은 개방면(전면)에 붙여 시야를 가리지 않는다.
    - 후면 카운터와 데스크 사이에 **간호사 통행 800mm**를 항상 확보하고, 그 통행 라인이 닿는 한쪽 팔에 **800mm 출입 개구부**를 낸다(간호처치실 쪽). 카운터 깊이는 `후면 카운터 40 + 통행 800 + 데스크 800 = 2,030mm`로 자동 산정된다.
    - 폭은 `팔 2개 + 2인 데스크 n조 × 피치 1,180mm` — 8석(4조) 기준 5,650mm로 25BED 도면의 카운터 실측 5,878mm와 일치한다.
15. **간호처치실·조제실은 N.S에 밀착**: 상단 스트립에서 `[N.S][간호처치실][조제실]` 순으로 벽을 공유하며 이어 붙인다(27bed 구성) — 처치·투약 준비가 스테이션 업무의 연장이기 때문이다. 스테이션 인접이 병상 자리보다 우선이므로 스트립에 병상 폭을 미리 예약하지 않으며, 스트립이 가득 차면 병상 밴드가 스트립 아래 전폭에서 시작한다. 반면 **간호사실(탈의·휴게)은 근무 공간이 아니므로 후방 밴드에 떨어져 배치**한다.
16. **환자 프런트 분리**: 화장실·탈의실·대기실은 처치·조제와 반대편(주 출입구 쪽)에 모아 환자 동선과 직원 동선이 교차하지 않게 한다.
17. **후방 실 누락 방지**: 선택한 후방 실의 높이 합이 열 용량을 넘으면 자동 실만 비례 축소해 전부 수용한다(최소 1,500mm 보장). 크기를 직접 지정한 실은 축소하지 않는다.
18. **죽은 공간 최소화**: ① 병상 밴드 구성(양면 n조 + 단면 행)을 탐색해 잔여 높이가 가장 작은 조합을 고르고, ② 남는 높이는 통로에 배분하되 요청 폭의 60%까지만 넓힌 뒤 나머지는 환자 밴드 깊이로 되돌리며, ③ 병상 격자에 딱 떨어지지 않는 잔여 폭은 주 동선이 흡수하고, ④ 환자 밴드는 후방 밴드 아래 구역까지 포함해 하단 전폭을 쓴다(주 동선 구간만 건너뜀). 측정 결과 면적 활용률 55% → **69%**, 죽은 공간 15% → **12%**.
19. **정수실 내부 자동 모델링**: 원수 인입 → 이송펌프 → Multimedia/Softner/Carbon 전처리 3연 → 5μ 필터 → RO(CWP106H/CWP66) 처리 순서와 Heating·Control Box·Main Panel·배수구를 자동 배치한다.

### 실사 렌더링 워크플로

이 뷰어 자체는 사진 수준의 실사 렌더러가 아닙니다. 실사 이미지가 필요하면 **glTF(.glb) 저장**으로 모델을 빼서 외부 렌더러에 넘기세요.

1. 3D 보기 → **glTF(.glb) 저장**
2. Blender(Cycles) · SketchUp + Enscape · Twinmotion · Lumion 등에서 .glb 임포트
3. 재질(바닥 비닐타일·벽 도장·스테인리스)과 조명(실내 조명기구·주광)을 입혀 렌더

모델의 재질은 이름이 유지된 채 내보내지므로, 렌더러에서 재질별로 한 번에 교체할 수 있습니다. OBJ는 지오메트리 호환이 더 넓지만 재질 정보가 단순하므로 glTF를 권장합니다.

> 오프라인 병원 내부망을 고려해 three.js도 `vendor/three/`에 번들되어 있습니다. 인터넷 연결은 필요 없습니다.
